# qa_python

Тесты для класса BooksCollector.

## Реализованные тесты

1. Проверка добавления книги в словарь books_genre.
2. Проверка, что у новой книги пустой жанр.
3. Проверка установки допустимого жанра.
4. Проверка получения жанра книги по её имени.
5. Проверка получения книг по определённому жанру.
6. Проверка получения текущего словаря books_genre.
7. Проверка получения книг, подходящих детям.
8. Проверка добавления книги в избранное.
9. Проверка получения списка избранных книг.
10. Проверка удаления книги из избранного.
11. Проверка, что книга с недопустимой длиной символов не добавляется.
12. Проверка, что недопустимый жанр не устанавливается.
13. Проверка, что книга не добавляется в избранное повторно.
