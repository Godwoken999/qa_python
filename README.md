# qa_python

Тесты для класса BooksCollector.

## Реализованные тесты

1. Проверка добавления двух книг.
2. Проверка, что у новой книги пустой жанр.
3. Проверка, что книга с недопустимой длиной символов не добавляется.
4. Проверка установки допустимого жанра.
5. Проверка, что недопустимый жанр не устанавливается.
6. Проверка получения книг по определённому жанру.
7. Проверка получения текущего словаря books_genre.
8. Проверка получения книг, подходящих детям.
9. Проверка добавления книги в избранное без дублей.
10. Проверка удаления книги из избранного.
